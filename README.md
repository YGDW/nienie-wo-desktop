# 捏捏窝电脑桌宠

[打开捏捏窝网页版](https://shy.pythonanywhere.com/)

把小伙伴带到桌面，透明悬浮在普通软件上方，随时捏一捏，也能隐藏起来。

## 下载和运行

[下载 Windows（微软桌面系统）64 位桌宠体验版 0.3.0](https://github.com/YGDW/nienie-wo-desktop/releases/download/v0.3.0/nienie-wo-windows-x64-v0.3.0.zip)

完整解压到固定文件夹。更新时先右键旧桌宠，选择“彻底退出”，再双击解压目录内的“捏捏窝桌宠.exe”。请保留旁边的资源文件。

## 操作

- 左键按住身体：捏动，松手回弹。
- 右键选择“移动位置”：下一次拖动用于摆放，松手回到捏动。
- 右键菜单可调大小、换角色、喂食、隐藏和彻底退出。

## 当前范围

电脑桌宠为单角色体验版；双角色同框与羁绊可在网页体验。自制角色可用备份文件导入，心情和零食暂不跨端同步。多显示器和其他电脑尚未完成验收。
