# 捏捏窝电脑桌宠下载发布方案

网站继续使用 https://shy.pythonanywhere.com/ ，公开下载包放在现有 GitHub（代码托管平台）账号 YGDW 下的专用公开仓库 nienie-wo-desktop。

只发布已验证的电脑程序压缩包和使用说明，不发布当前聊天记录、个人存档、凭据或项目开发目录。安装包来源与摘要见 publish-plan.json。

电脑程序当前为单角色体验版，支持透明悬浮、捏动、喂食、尺寸档位、隐藏退出及位置记忆。双角色和羁绊目前在网页版使用；网页与桌宠存档尚未自动同步。

用户取得安装包后，完整解压，先退出旧桌宠，再运行文件夹内的“捏捏窝桌宠.exe”。第三方许可证随程序保留。
